# Lecture Voice-to-Notes Generator using AI

This project is an AI-based prototype system that converts recorded lecture audio into text and automatically generates summarized study notes using speech-to-text and NLP techniques.

## Technologies Used
- Python
- SpeechRecognition
- NLP (Text Summarization)
- Streamlit

## Features
- Upload recorded lecture audio
- Convert speech to text
- Generate summarized notes
- Simple and user-friendly interface

## Note
This is a prototype-level academic project developed as part of an IDM / AICTE internship.
